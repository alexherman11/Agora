4 · Where it hurts

What the shape does to them

Three rule books that disagree

JEFF gets your 681-word rules. Sable and Pike get a 130-word copy from 27 Oct. Rowan gets a 237-word Codex version from 28 Oct. A rule you add to your rules never reaches the residents.

ran

The flow is explained ten times, in three voices

"How work flows" explains it once, plainly. Then nine messages each explain it again in their own words. The header on every wake explains it a third way: "Receipt is not review… Held/unknown work requires its stated resolver". That old voice teaches them to wait. The new guide teaches them to finish.

read

The whole task list on every wake

Every wake carries 220 to 370 words of task list, even when nothing changed. All 8 of JEFF's items read "result awaiting owner review · acceptance: missing · reviewed=no · verified=no". It is noise, and it reads like a list of things that are stuck.

ran

JEFF is woken by the board

JEFF is the only one woken whenever his task list changes, so every card change near him costs a turn. Meanwhile "a card was given to you" now wakes nobody: the code skips anyone with a task list, and all four have one.

5 · Proposal imagined

One Agent Book, in Writing

Everything that reaches any agent comes from one Writing document, the Agent Book. You edit it like any other page. The House reads it by heading at each wake, so an edit counts on the next wake with no restart. The code keeps only the mechanics: which headings each class gets, and filling blanks like {worker}.

R1

One Agent Book, read by heading

Promote "Agent prompts" from a snapshot to the live source: rename it Agent Book and give it the headings above. The House reads each heading when it builds a message. A missing heading falls back to the current text, and the House says so in Shop talk.

One place to edit. What you see in Writing is what they get.

R2

One rule book for everyone

Your standing rules go to all four house-agents and to every worker. The three copies get a superseded banner and are archived, not deleted.

A rule you add reaches everyone, including the residents.

R3

Say the how-to once

The Role pages hold the flow. Each message is one line of what happened. The nine how-to paragraphs and the "receipt is not review" header go away.

One voice. And it is the voice that says finish, not hold.

R4

Task list only when it changes

The full list goes out on a fresh start and after a compaction. Every other wake gets one line of what changed, or nothing. The "acceptance: missing · reviewed=no" fields leave the list.

A plain wake drops from about 420 words to about 40.

R5

The same wake rules for everyone

JEFF is woken when addressed, like the residents, not by board churn. A card given to someone wakes that one person once.

This fixes the dead "card given to you" path and JEFF's stream of extra turns.

R6

Workers are told to finish

The brief comes from the Book, not AGENTS.md. In place of "ask when unclear", it says: decide, note the assumption, test, finish. Stop only for the ask-first list. This pairs with the House finishing the loop itself (in "Why the agents stall"): review, land and check run on their own, and the owner gets one message at the end.

The owner messages per task go from four or five to one.

R7

One builder for starts and compactions

A fresh start and a compaction build the same message once, from the Book. Nothing is sent twice. Rowan moves onto the same flow as the others (house.work, review, land).

Fewer paths, and fewer places for drift.
