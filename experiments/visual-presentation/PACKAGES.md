# Retained experiment packages

`presentation/` contains JEFF's final native action package, including the authored
circle family. `shell/` contains the subsequent review shell with the corrected
action-registry lookup, selection continuity and visible transient preview.
`schemas.json` contains the experimental application schema declarations.

These are examples retained from isolated synthetic worlds. Installation requires
the corresponding schema admission and package save/build/install operations in
an explicitly selected world. Python candidate execution needs the separate yard;
both guest environments need Node 18.19.1 or a verified compatible runtime.
Nothing in this archive automatically activates code or changes a person's world.
Experiment receipt IDs identify the original evidence, not identities to reuse
when installing into a new world. The adapter remains coupled to this shell and
is not a general surface-registration implementation.
