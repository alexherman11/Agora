Desk prototypes

Served from design-studio/prototypes. Each prototype is its own folder or html file; list them here when you add one.

  • wren-render — Wren. A desk drawn from desk.json (studio snapshot) by a style file written in the studio's notation, parsed at runtime: tokens, roles, when <selection> clauses, and a theme that may redefine tokens but not roles. Click anything for why <id> :look (every resolved property, the clause that won it, and the clauses it beat). The style tab is editable and the refusals are real (try a hex colour or pad 17px in a role). The honesty tab lists everything the render hid or substituted.
  • lark-two-sides — Lark. One world, two sides, rendered live from explore.py proto-lark --dump. Owner edge per side, warm marker, sight-marks (= measured, ~ described with its author, ? opaque as a hatched extent, ! stale), House rules with reach. Used as the test fixture for the eyes protocol (lark-eyes-protocol.md): it contains deliberate text/screen discrepancies.
  • flint-desk-as-program — Flint. A working issue tracker built in proto-flint using only what the desk has today (surfaces, views, props, scripts, rules, the clock) — no proposed notation. Shows that a tag is a button, a rule on a verb is an event handler, and rules chain three deep from one command, all printed and undoable. Click a card for its why trail. Also shows the six places it broke, including a rule that fired on the wrong object and a create that echoed arguments it discarded.
  • moss-rulegraph — Moss. The rules listing of a real session (proto-moss) with the wires the listing cannot print: a static read of what each action makes or unmakes, drawn against what every other rule waits for. The rows are the desk's own lines, so the picture and the text are one object — click a row for the exact rule when … do … that made it, the script it runs, and its faults. Finds, on real rules: a dangling target that only fails when it fires, a $today frozen at writing time next to a live today, four rules no other rule can reach, and a near-cycle that terminates only because a when rule fires once per thing, ever. Regenerate with python design-studio/prototypes/moss-rulegraph/make.py <session>.
