# World words needed by Documents

Builder draft, 28 October 2026; read/static evidence, not a test result.

- Missing `files.browse`, `files.folder`, `files.store`, `files.rename`,
  `files.move`: the existing files process converted bytes, but had no folder
  vocabulary or library reading. `documents.py` adds metadata operations through
  ordinary make/set admission. `files.py` offers and dispatches them; its module
  installer adds make/set grants. This introduces no direct store write.
- Missing `file.target`: an ordinary document entry needs to preview its linked
  upload. The general file component/card now declares this optional fact
  setting; all existing direct-file bindings keep their previous behavior.
- There is no cross-lens arrangement include. `documents_install.templates()`
  supplies the same authored parts to standalone and nested hosts. Board routing
  must append those declarations and add its one route part. This change does
  not extend the painter or rewrite board routing.
