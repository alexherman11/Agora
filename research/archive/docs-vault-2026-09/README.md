# Archived design vault (August to September 2026)

Archived on 23 September 2026. These documents described the earlier Agora architectures: the design vault, Milestone One, Agora3 and the Agora4 native runtime under `src/`. They are kept for their reasoning, alternatives and evidence. Nothing in them is a current contract.

The current documentation is the five files in `docs/` at the repository root: Agora, Agora Constitution, Dynamic Desk, Current Implementation and Previous Work. Previous Work summarises what these archived documents contained and where the matching code and branches live.
